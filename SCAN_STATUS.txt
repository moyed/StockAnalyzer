STEP 2: View Results
After login, you'll see the dashboard with 2 companies.

If you DON'T see companies:
❌ You're not logged in
   → Check navbar: should show "Logout" button
   → If it shows "Login", you need to login again

❌ Browser console has errors
   → Press F12 → Console tab
   → Look for red error messages
   → Common: "401 Unauthorized" = login expired

❌ API is not responding
   → Test: curl http://localhost:8000/api/companies
   → Should return: {"message":"Unauthenticated."}

Problem: "I don't see any companies"
Solution: You MUST login first!

Problem: "Companies page is blank"
Solution: 
1. Check browser console (F12)
2. Look for 401 error = need to login
3. Look for network error = API down

Problem: "Login button does nothing"
Solution: See LOGIN_TROUBLESHOOTING.md

Problem: "How do I know scan is done?"
Answer: Check the "Scan" page status badges:
  🟢 done = complete
  🟡 pending = waiting
  🟠 processing = in progress
  🔴 failed = error
